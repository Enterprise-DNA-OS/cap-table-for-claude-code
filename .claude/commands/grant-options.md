---
description: Grant share options under a plan, checked against what is left in the pool.
---

Confirm holder, plan, quantity, exercise price, vesting start, months, cliff and expiry, and the board approval date. Run `npm run cap -- grant-options <holder> --company=<code> --plan=<code> --quantity=<n> --price=<price> [--start=] [--months=48] [--cliff=12] [--every=1] [--expires=] [--approved-on=]`. Say the fair value on file next to the exercise price.
