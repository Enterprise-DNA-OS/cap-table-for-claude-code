---
description: Every filing the register owes (NZ share issue notices, ASIC Form 484, ATO ESS statements and report, NZ ESS income), with due dates and what is already lodged.
---

Run `npm run cap -- filings --company=<code>`. Overdue first, then due soon. Each row names the event behind it. To produce the list for whoever lodges, run /draft-filings. Once lodged, /record-filing.
