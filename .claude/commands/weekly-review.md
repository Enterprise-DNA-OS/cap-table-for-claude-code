---
description: The Monday share register review, written from attention, filings, vesting and the rule checks.
---

Run `npm run cap -- attention`, `npm run cap -- filings` and `npm run cap -- vesting --days=30`. Write five lines: what must be lodged this week and by whom, who vests or hits a cliff, which leavers have to decide, the rule findings, one thing to raise with the board. Then run /draft-weekly to save it.
