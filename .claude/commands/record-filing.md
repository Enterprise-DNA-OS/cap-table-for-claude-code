---
description: Record that a filing was lodged, so it stops showing as owed.
---

Ask for the company, the filing kind, the subject (the share event code, or FY2026 for an ESS year) and the date lodged. Run `npm run cap -- record-filing --company=<code> --kind=<kind> --subject=<ref> --on=YYYY-MM-DD --reference=<receipt> --by=<name>`. Say whether it was late.
