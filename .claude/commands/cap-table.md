description: The cap table: every holder's ordinary and preference shares, outstanding options and the unallocated pool, issued and fully diluted percentages.
---

Run `npm run cap -- cap-table --company=<code>`. Present it as a table, largest holders first, pool last. Say the totals in one line: issued shares, fully diluted shares, the founders' combined fully diluted share. If the operator asks "what does X own", use /stakeholder instead.
