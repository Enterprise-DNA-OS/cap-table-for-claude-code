---
description: Issue new shares to a holder and see the filing it triggers.
---

Confirm the holder, class, number of shares, price and the board approval date. Run `npm run cap -- issue-shares <holder> --company=<code> --class=<code> --shares=<n> --price=<price> [--on=] [--round=] [--approved-on=] [--certificate=]`. Report the event code and the filing due. Add the holder first with /add if they are new.
